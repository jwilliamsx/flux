# Flux - Analisador de Trânsito

Sistema de análise de acidentes rodoviários focado no estado de Pernambuco.

## Funcionalidades
- Sincronização automática de dados do DATATRAN.
- Filtros por ano e UF.
- Análise de trechos específicos entre cidades.
- Mapa de calor de ocorrências.
- Estatísticas de causas e horários.

## Como executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o Streamlit: `streamlit run app.py`
